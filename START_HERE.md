# Start here

GPT Chat Local Bridge is an experimental bridge between standard ChatGPT Chat and a Windows worker, with GitHub used as transport.

The **single cross-chat source of truth** is [CONTINUITY.md](CONTINUITY.md). It contains verified progress, blockers, exact branches, the next action and a copyable prompt for a new chat with no memory.

See [AGENTS.md](AGENTS.md) for the update convention and safe collaboration boundaries, and [docs/PILOT_PROTOCOL.md](docs/PILOT_PROTOCOL.md) for the planned pilot.

**Status:** no local worker has been installed or demonstrated running. The strict offline protocol validator is drafted on `feat/pilot-schema-v0`, and its unit tests still need to be run.
